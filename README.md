# Frontend Engineer — Take-home / Live-coding

Welcome! You have **30 minutes**.

## Setup

```bash
npm install
npm run dev
# open http://localhost:3009
```

## What to do

1. Open <http://localhost:3009> and click **Open the test page**.
2. The page is a small restaurant menu with an "add to cart" interaction.
3. **Find what is wrong, fix it, and make the page better.**

A few small hints are printed on the page itself — but they only point to part of the story. There is more to find than what is hinted.

## What we look for

- How you read code and use the browser DevTools (Console, Network, Inspect).
- How you reason about React performance.
- How you think about the **product** — what would you, as a user, want this page to do that it doesn't?

You don't have to finish everything. Talk us through your thinking as you go.
